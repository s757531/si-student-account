## 🚀 দ্রুত শুরু

### **প্রয়োজনীয়তা**
- Python 3.8+
- pip (Python প্যাকেজ ম্যানেজার)
- Telegram Bot Token (BotFather থেকে পান)

### **ইনস্টলেশন**

1. **রেপোজিটরি ক্লোন করুন**
```bash
git clone https://github.com/s757531/si-student-account.git
cd si-student-account
```

2. **পাইথন এনভায়রনমেন্ট তৈরি করুন**
```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# অথবা
venv\Scripts\activate  # Windows
```

3. **ডিপেন্ডেন্সি ইনস্টল করুন**
```bash
pip install -r requirements.txt
```

4. **.env ফাইল তৈরি করুন**
```bash
cp .env.example .env
```

5. **.env ফাইল এডিট করুন**
```
TELEGRAM_BOT_TOKEN=your_bot_token
ADMIN_USERNAME=admin
ADMIN_PASSWORD=your_password
```

6. **ডাটাবেস ইনিশিয়ালাইজ করুন**
```bash
python database/db.py
```

7. **অ্যাপ্লিকেশন চালান**
```bash
python run.py
```

## 🎓 ব্যবহার

### **স্টুডেন্টদের জন্য**
1. টেলিগ্রামে বট খুলুন
2. `/start` কমান্ড দিন
3. রেজিস্ট্রেশন ফর্ম পূরণ করুন
4. ইমেইল ভেরিফিকেশন সম্পন্ন করুন
5. ক্রেডিট লোড করুন এবং কাজ শুরু করুন

### **এডমিনদের জন্য**
1. `http://localhost:5000` এ এডমিন প্যানেল অ্যাক্সেস করুন
2. অ্যাডমিন ক্রেডেনশিয়াল দিয়ে লগইন করুন
3. স্টুডেন্ট ডাটা, ক্রেডিট এবং কাজ ম্যানেজ করুন

## 📊 ডাটাবেস টেবিল
